# 📱 iDowngrade Simulator Platform

Welcome to **iDowngrade**, the #1 best interactive simulation layout built for vintage Apple firmware fans! Our layout engine is designed to model custom hardware configuration validation paths across multiple generations of devices.

## 🚀 Key Platform Features
* **100% Untethered Configurations:** Fully modeled tether-free, glitch-free simulation outputs.
* **Strict Hardware Bound Rules:** Active criteria limits check for matching devices (iPhone, iPad, iPod Touch, Mac).
* **Sleek Personality Styles:** Built-in responsive light and dark mode viewport background toggles.
* **Source Guard Layer:** Background mechanics shield properties and configuration arrays from casual inspector tools.

## 🛠️ Project File Layout
* `index.html` - The structural card container, graphical interface layout, and custom theme designs.
* `script.js` - The main data checking script engine, terminal animation loader, and layout toggles.
